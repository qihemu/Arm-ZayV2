# damiao_hardware

`DamiaoSystemHardware` 是 Humble `hardware_interface::SystemInterface` 适配层，可在一条 SocketCAN 总线上注册一到六台达妙电机。每轴导出 position 命令和 position/velocity 状态，单位为 rad、rad/s。单轴 DEV-07 接口保持兼容；六轴参数放在各 joint 的 `<param>` 中，所有接口数值使用插件内固定数组，句柄地址不会因运行期扩容改变。

## 六轴控制路径

- `on_init` 校验全部关节接口、逻辑名称、CAN 地址、坐标转换、机械范围和反馈期限。初始状态与命令均为 NaN，不访问 CAN。
- `on_configure` 在一个 `DamiaoBus` 中注册全部电机并独占总线，逐台读回模式与映射范围，核对失能状态和实测位置。若实测关节角度超限，记录错误但保持 `inactive`，继续通过状态接口报告实测角度；每次请求 `active` 时重新查询全部关节，任何一轴超限都会拒绝使能并保持 `inactive`，调整角度后可重试。失能期由后台线程顺序发送无运动状态查询。
- 默认 `allow_enable_on_activate: false`。明确开启后，`on_activate` 先核对六轴全部反馈，再逐台使能并检查位置变化，随后再次核对整组六轴反馈；全部通过才打开整组发送许可并发一批保持目标。任一步失败均撤销许可并尝试逐台失能。
- 活动期 `read()` 一次取六轴缓存快照，先校验每轴新鲜度、状态和关节限位，再更新全部状态句柄。`write()` 根据实际发送间隔检查周期超时、目标有限性和关节限位；轨迹重规划产生的合法目标跳变按各轴配置速度上限的 90% 逐周期限幅，并用实际发送值更新下周期基准。激活保持目标后的首批常规发送至少间隔 10 ms，再调用 `send_position_velocity_batch()`。非有限目标、越界、周期超时和 CAN 故障仍会锁存错误。核心库按 CAN 帧顺序发送；同一控制周期的整组目标不等于电机在同一物理时刻接收。
- `on_deactivate` 撤销整组许可并逐台失能。读写故障锁存，不自动恢复旧目标；失能失败会记录具体电机和错误。

## 实机边界

默认配置只允许加载和状态检查。六轴使能时序、掉电/断连、位置源与零位、设备 TIMEOUT、承重关节支撑和停止策略尚需逐轴及整机台架验证。当前失活策略是显式失能，**不适合无外部支撑的承重关节**。`model` 和实体唯一身份不能仅靠当前协议读回证明。禁止把软件加载测试等同于真机安全或轨迹性能验收。

启动配置与操作见 `zayv2_bringup/README.md`。插件不会自动改 ID、切模式、写 Flash 或建立机械制动能力。
