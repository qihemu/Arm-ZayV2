# ZayV2 实施状态与下一步

更新日期：2026-09-25。本文按当前源码区分**软件已实现**与**实机已验收**；没有台架记录的项目均不算通过实机验收。详细设计与风险项见 [达妙开发文档](damiao-development-guide.md)。

## 当前软件基线

| 模块 | 已实现 | 尚需验证或补齐 |
| --- | --- | --- |
| 机器人模型与上层 | ZayV2 六轴 URDF/SRDF、MoveIt 和 Servo Mock 演示 | 实体尺寸、惯量、关节轴、碰撞模型、TCP、负载及加速度上限 |
| 通信与调试 | `damiao_core` 的 SocketCAN/多轴协议；`damiao_tools` 的扫描、查询、位置速度驱动、模式维护、Flash 保存、动作序列 | 设备固件协议、反馈位置源、TIMEOUT、断连及停止的实测记录 |
| 电机零点写入 | CLI 菜单 11 在确认全轴失能和操作者输入 `YES` 后，对选中电机发送保存零点命令；成功后刷新状态和保持目标 | 写入后的掉电保持、位置源变化及机械零位复核；异常回执时先读回，避免重复写入 |
| 关节标定映射 | 单轴/六轴配置包含电机 ID、方向、`zero_offset_motor_output_rad`、额外传动比和关节限位；插件使用这些值做电机/关节坐标转换 | 每轴实物零偏、方向、限位、跨圈与重启一致性；版本化标定记录尚未实现 |
| 真机 ros2_control | `damiao_hardware/DamiaoSystemHardware` 支持 1～6 轴，导出 position 命令及 position/velocity 状态；单轴/六轴 launch、JTC、状态广播器和六轴状态监视器已接入 | 单轴及六轴真实轨迹、时序、部分故障、失能和重启验收 |
| bringup 测试界面 | `damiao_slider_test_gui.py` 从控制器实测状态初始化滑块并发送整组轨迹；“回零”发送六轴 0 rad 目标 | 真机反馈和轨迹结果验证；该操作不调用 `damiao_tools` 的零点写入 |

Mock 启动仍使用 `mock_components/GenericSystem`。真机入口为 `zayv2_bringup` 的 `damiao_single_axis.launch.py` 与 `damiao_six_axis.launch.py`；两套入口应分开运行。操作说明见 [真机 bringup](../src/zayv2_bringup/README.md)，插件边界见 [硬件插件](../src/damiao_hardware/README.md)，电机零点操作见 [调试工具](../src/damiao_tools/README.md)。

### 三项独立操作

| 操作 | 所属组件 | 作用 |
| --- | --- | --- |
| 保存电机零点 | `damiao_tools` 菜单 11，经 `damiao_core::DamiaoBus::save_zero()` | 向选中电机写入零点，改变电机坐标基准；要求全轴失能和 `YES` 确认 |
| 设置关节零偏 | `zayv2_bringup` 真机 YAML 中的 `zero_offset_motor_output_rad` | 配置机械关节零位对应的电机输出角；需要实物测量和复核，不由 GUI 自动生成 |
| 运动到关节零位 | `zayv2_bringup` 的六轴滑块 GUI，经 `arm_controller` | 发送六轴关节目标 0 rad 的轨迹；不会保存电机零点或修改 YAML |

电机零点写入后必须重新核对关节零偏；更换电机或传动件后也需重新测量。三项操作之间没有自动调用关系。

## 下一步执行顺序

| 优先级 | 工作 | 完成证据 |
| --- | --- | --- |
| P0 | 整理六轴设备与机械参数：型号/电压/固件/ID、供电、方向、机械行程、负载和承重轴失能支撑；确定独立急停和受限台架 | 逐轴参数表、负载核算、停止与支撑方案均有记录 |
| P1 | 单轴只读及关节标定验证：核对模式/映射、普通反馈 POS 与 `p_m`/`xout`、掉电和跨圈行为，形成关节零偏记录；另对 `damiao_tools` 的电机零点写入做独立台架验收 | 原始帧、位置对照、关节标定与重启一致性记录；电机零点写入前后坐标单独记录 |
| P2 | 单轴受限运动及 ros2_control 验收：先用 CLI 低速验证使能、失能、TIMEOUT、断连，再用单轴 JTC 执行小幅轨迹 | 首次使能无意外跳变；真实 `/joint_states`、轨迹误差、故障与重启结果可复现 |
| P3 | 六轴联调：校验 ID 无冲突、每轴方向/零偏/限位、整组使能与故障联动，记录 100 Hz 周期、反馈年龄和跟踪误差 | 六轴无串轴；逐轴断连与故障时整组进入预期状态；时间预算和停止距离有实测结果 |
| P4 | MoveIt 真机执行：核对实体模型和限位，整改上层状态失效兜底、部分路径成功语义与取消流程；从小幅关节轨迹扩展到点到点和笛卡尔路径 | 规划与执行结果、终点误差、取消和异常恢复均有记录 |
| P5 | Servo 与持续运行：实现规划/Servo/GUI 命令来源互斥、输入有效期及运行诊断，逐步提高速度和负载 | 控制权切换、输入过期、温升、失联与长期运行符合项目指标 |

前一阶段的**软件实现**可以先完成，只有取得对应实机证据后才进入后续带载运动。当前应优先完成 P0 和 P1，同时准备 P2 的单轴轨迹测试。状态监视器会在硬件退出 active 后关闭六轴 launch，但它不构成硬件急停或承重关节制动能力。
