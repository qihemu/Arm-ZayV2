说明：

- `zero_offset_motor_output_rad` 取自电机**输出轴**角度读数，记录时假定机械臂处于**零位姿态**；重标零位后须同步改 YAML。
- `extra_reduction` 为电机输出轴到关节之间的**额外**传动比；机内减速比（Gr）已在电机内，**勿在软件中重复乘算**，且说明书要求勿改 Gr 寄存器。
- 关节限位与 `zayv2_description.urdf` 一致；`max_velocity_rad_s` 取 URDF 上限 3.0 rad/s，低于电机寄存器 VMAX 映射。
- `bus.allow_enable_on_activate` 当前为 `false`；使能策略见 `src/zayv2_bringup/README.md`。

**保护（说明书建议，24V/48V 过压阈值不同）**

| 项目 | 说明 |
| --- | --- |
| 驱动过温 | 120 ℃ 退出使能 |
| 电机过温 | 可配置，建议 ≤ 100 ℃ |
| 过压 | 24V 版建议 ≤ 32 V；48V 版建议 ≤ 60 V |
| 欠压 | 建议电源不低于 15 V |
| 通讯丢失 | 超时未收到 CAN 指令退出使能 |
| 过流 | 可配置，建议不超过 9.8 A（相电流相关，以寄存器/助手为准） |

**工作电压范围（说明书）**：24V 版约 20–28 V；48V 版约 20–58 V（>36 V 建议减少热插拔）。

**扭矩系数（输出轴）**：\(K_t = 1.5 \times N_{pp} \times \psi_f \times GR \times G_{REF}\)（\(G_{REF}\) 为减速箱力矩传递系数，标定后写入电机）。

## 5. 后续开发使用说明

1. **改 ID / 映射 / 零位**：先改电机或 YAML，再跑 `damiao_tools` 读回核对，并更新本文 §1、§2。
2. **动力学与 MoveIt**：质量惯量优先用 §4 实测填入 URDF 或 `ros2_control` 附加负载；在未实测前可暂用 CAD，但需在仿真/力控结果上标注不确定性。
3. **力矩与速度规划**：关节侧限矩需结合 **TMAX 映射** 与机械减速比；J1/J2 峰值扭矩远高于 J3–J6，混用型号时按关节分级限速限矩。
4. **文档同步**：`six_axis.example.yaml` 与本文冲突时，以 **已台架验证的 YAML** 为准，并回写本文修订记录。
